# منصة الكورسات التعليمية

منصة تعليمية لعرض الكورسات مع backend لتسجيل الحسابات والدخول باستخدام SQLite.

## التشغيل

يتطلب Node.js 22.5 أو أحدث. من مجلد المشروع:

```sh
npm install
npm start
```

ثم افتح [http://127.0.0.1:8000](http://127.0.0.1:8000).

## الحسابات

أنشئ حسابًا من صفحة تسجيل الدخول؛ تُخزّن بيانات الحسابات في `data/courses.sqlite`، وتُشتق كلمات المرور باستخدام scrypt مع salt عشوائي. جلسات الدخول تُحفظ كرموز عشوائية مجزأة في قاعدة البيانات وتُرسل للمتصفح عبر cookie من نوع HttpOnly وSameSite.

الحسابات التي أُنشئت سابقًا في التخزين المحلي للمتصفح لا تُنقل تلقائيًا؛ أنشئ حسابًا جديدًا على الخادم.

## حدود الوظائف الحالية

آراء المتعلمين والتسجيل في الكورسات ما زالا محفوظين محليًا في المتصفح، ولا تتحقق واجهتهما من جلسة الخادم. الدفع محاكاة فقط؛ لا تُدخل بيانات بطاقة حقيقية. هذا backend مناسب للتطوير المحلي؛ قبل النشر يلزم إعداد HTTPS، وبيانات اعتماد وقواعد تشغيل إنتاجية، ومزوّد متخصص للدفع.
