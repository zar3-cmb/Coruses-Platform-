# منصة الكورسات التعليمية

موقع تعليمي بواجهة أمامية لعرض الكورسات وإدارة دخول محلي ونشر آراء المتعلمين.

## التشغيل

من مجلد المشروع:

```sh
npm install
npm start
```

ثم افتح [http://localhost:8000](http://localhost:8000). يتطلب الأمر تثبيت Python لتشغيل خادم الملفات المحلي.

## تنبيه

إنشاء الحسابات والآراء يعملان محليًا في المتصفح، ولا تتم مزامنتهما بين الأجهزة أو إرسال بياناتهما إلى خادم. هذا التخزين ليس بديلًا عن المصادقة الآمنة أو قاعدة بيانات إنتاجية. تبقى عملية الدفع محاكاة فقط؛ لا تُدخل بيانات بطاقة حقيقية. لتفعيل الحسابات والآراء المشتركة والدفع في الإنتاج، يلزم خادم آمن ومزوّد متخصص للمصادقة والدفع.
